# Source ratings (`source-ratings.json`)

Domain listings used by source vetting (`src/vetting/ratings.ts`). Generated by
`node scripts/build-source-ratings.mjs <domains.csv>` from the labelled dataset in
`todo/propaganda-detection/propaganda-dataset` (built 2026-11-14 by merging public lists).
Rows labelled `mixed` (low confidence, "everything else") are left out: an unlisted domain has
no rating, which is not a signal either way.

| Label | Domains | Used as |
|---|---|---|
| propaganda | 6,846 | `influence_operation` (covert operations: **manipulative**) or `state_media` (overt state media: caution → uncertain) |
| unreliable | 4,104 | caution → uncertain (ratings are contested; never manipulative on their own) |
| satire | 50 | caution → uncertain |
| reliable | 2,580 | positive signal |

Row format: `[label, confidence, actor_country, subtypes, sources, lin_pc1, name]`.

## Limitations
- Propaganda class is ~95% Russian (Meta Doppelganger spoof domains); non-Russian coverage is thin.
- Lists include operations run from democracies; a listing means "a documented coordinated influence
  operation", not a judgement about any government.
- MBFC/NewsGuard-derived ratings are disputed (e.g. foxnews.com is "unreliable" here): they only ever
  lower a verdict to "uncertain", with attribution.
- Many listed domains are dead or rotate quickly; absence from the list proves nothing.
- Check licences before redistributing the data or using it commercially.
